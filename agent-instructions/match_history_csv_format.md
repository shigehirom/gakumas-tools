π# match_history_XX.csv のフォーマット

- 1行目で各フィールドを定義する。内容は以下で固定。
```csv
日付,相手名,メモ,獲得Pt,自S1,敵S1,自S2,敵S2,自S3,敵S3,結果
```

以下、各フィールドについて説明する。

- 日付: YY/MM/DD 形式。同一日に5回対戦できることから、同じ日付の行が5回出現する。
- 相手名: 対戦相手の名前。デフォルトは空欄。
- メモ: 対戦相手のグレード(1~3)を入力する。デフォルトは3で固定。
- 獲得Pt: その回の対戦で獲得したレートPtを入力。デフォルトは空欄。
- 自S1,敵S1,自S2,敵S2,自S3,敵S3: 各ステージでのスコア。デフォルトは空欄。
- 結果: WIN or LOSEを入力。デフォルトとして"WIN LOSE"を入れておく。

# match_history_XX.csv の生成方法
前述のフォーマットに従って、専用のスクリプトで生成する。UIからは
$ pnpm cli match-history XX 2026/7/6 2026/7/22 
のように開始日と終了日(翌日)を指定することで、日付列が 26/07/06 から 26/07/21 と記載された CSV が生成される。
