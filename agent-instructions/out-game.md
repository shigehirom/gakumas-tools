# 学園アイドルマスター out-game

## HIF編 選抜試験編

### プロデュース前準備
#### プロデュース編成の登録
##### サポート編成
- 事前に、手持ちのサポートカードより5枚を設定して「編成」に登録しておく。
	- サポートカードは予めデータベースに登録した育成レベルの情報を伴うものであり、当該育成レベルで発動するアビリティやその際のパラメータの値が明確になっている。
	- サポートカードの諸元については、各サポートカード毎に out-game 用DSL で定義されている。
	- データベースは、MongoDB gakumas-tools に新たなサポート編成用のコレクションを作成する想定。
		- そのデータベースに登録されるサポート編成のデータは以下の通り:
			- 編成名
			- プロデュース種別 (「初」「NIA」「HIF」)の3種類。当初は「HIF」のみ。
			- 5つのサポートカード
				- サポートカードのID
				- サポートカードの育成レベル
##### メモリー編成
- 事前に、手持ちのメモリーの「プロデュース」に登録されたスキルカードを4枚設定して「編成」に登録しておく。
	- MongoDB gakumas-tools の memories のデータを拡張して、「プロデュース」用スキルカードに関するデータを新たに保存する想定。
		- 現在の memories は in-game で使われる「ステージ」用のデータ(Vo/Da/Vi/Stamina, Pアイテム, スキルカード)の情報が保存されている。
		- このデータに対して新たに以下の「プロデュース用」スキルカードに関する情報を追加するイメージ。
			- 獲得可能スキルカード
				- in-game 用のスキルカードデータを参照する(ID)。
				- カスタマイズに関する情報もin-gameのそれを流用。
			- スキルカード獲得タイミング
				- 開始時に獲得
				- 中間試験/1次オーディション後に獲得
			- アビリティ: 最大3つ分。out-game 用の DSL で定義。
				- 初期パラメータ増分
				- パラメータボーナス増分
			- プロデュース専用アビリティ
				- 「初」編
					- 特定レッスン開始時に付与されるバフ情報
				- 「NIA」編
					- 1次または2次オーディション開始時に付与されるバフ情報
				- 「HIF」編
					- 特定スキルカードを使用時に発動
					- 指定回数まで発動
					- スキルカードの使用数追加 or ランダムな山札か捨札の「眠気」を除外に移動
