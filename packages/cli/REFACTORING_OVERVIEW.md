# 学園アイドルマスター ツール CLI リファクタリング概要 (2026年5月)

VS Code, Roo Code, および Google AI Studio (Gemini 1.5 Pro/Flash) を活用して実施された、`packages/cli` の大規模なリファクタリングの概要を以下にまとめます。

## 1. アーキテクチャの刷新：TypeScript への移行
従来の個別 `.mjs` スクリプトの直接実行から、TypeScript ベースの統合 CLI フレームワークへと移行しました。

- **コマンド管理の統合**: `cac` ライブラリを採用し、サブコマンド形式 (`yarn cli contest`, `yarn cli rehearsal` 等) での実行を可能にしました。
- **モジュール化**: `src/commands/` 配下に各コマンドのロジックを分離し、保守性を向上させました。
- **ランナーパターンの導入**: 高性能な計算が必要な既存のシミュレーションエンジン（Node.js JS）を「ワーカー」として実行し、TS CLI がそのオーケストレーションと UI 表示を担う構造に分離しました。

## 2. プレゼンテーションレイヤーの強化 (UX/UI)
ターミナル出力の可読性を大幅に向上させ、プロフェッショナルなレポート出力を実現しました。

- **Handlebars テンプレート**: `src/templates/` 配下に Markdown 形式のテンプレートを用意し、複雑なシミュレーション結果を整理されたテーブル形式で表示します。
- **リアルタイム・ストリーム解析**: シミュレーションプロセスから出力される JSON ストリームを解析し、完了した結果から順次テンプレートを適用して表示する仕組みを導入しました。
- **スマート・デフォルト**: 実行条件（ステージ、アイドル名など）に基づいて、出力ファイル名やレポートタイトルを自動生成するロジックを実装しました。

## 3. クラウド連携と自動化
計算結果の共有と永続化を自動化する機能を統合しました。

- **Google Drive 自動アップロード**: `--gdrive` オプションにより、CLI の出力をそのまま Google Drive へ Markdown ファイルとしてアップロードする機能を実装。
    - `GoogleDriveClient`: サービスアカウントを使用したセキュアなアップロード。
    - `GlobalCapture`: `stdout` をインターセプトし、ターミナルへの表示とファイル保存を両立。
- **環境設定の堅牢化**: `.env.local` の自動探索ロジックにより、異なるディレクトリ階層からの実行でも正しく認証情報を取得できるようにしました。

## 4. シミュレーション機能の高度化
既存のロジックを維持しつつ、CLI からより詳細な制御を可能にしました。

- **パラメータ制御の細分化**: `--supportBonus`, `--force` (キャッシュ無視), `--save` (ロードアウト保存) 等のオプションを TS レイヤーで統括。
- **比較分析機能**: `--compare` オプションにより、特定のパターン（「再生成*」等）に合致するメモリの性能比較を自動化。
- **ステップ実行統計**: 2フェーズシミュレーションにおける枝刈り状況などの詳細な統計表示に対応。
